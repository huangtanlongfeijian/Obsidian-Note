# 印度cib&rc474的出口数据更新
## 一、会议概况
第474次注册委员会会议审议了涵盖新注册、标签扩展、化学等效性评估、进口/出口许可及行政事项等多类议程，形成了一系列批准、驳回和待处理决定。

---
## 二、主要批准事项
### （一）新注册批准
**9(3)新制剂注册（3项）：**
- **Nichino India**：Flubendiamide + Emamectin Benzoate ME，用于玉米（秋粘虫、茎蛀虫）和大豆（茎蝇、半翅目、豆荚蛀虫）
- **Krishi Rasayan Exports**：Azoxystrobin + Isoprothiolane + Validamycin WDG，用于水稻稻瘟病和纹枯病
- **Bayer CropScience**：Ethiprole + Benzypyrimoxan SC，用于水稻飞虱和叶蝉
以上均需在2.5年内提交30个月实际稳定性数据，否则注册自动取消。

**9(3)原药注册：**
- **Deccan Fine Chemicals**：Florpyrauxifen-benzyl Technical 94%（TIM vs TI），化学等效性评估通过，工艺改进获认可
- **Crystal Crop Protection**：Carfentrazone ethyl Technical 90%（需补充致突变性数据）

**9(4)原药进口注册（多项）：**
批准了多家公司的技术进口注册，均附条件：**须提交海外来源工厂的详细验证地址及GEO标记证明**。涉及产品包括：Emamectin Benzoate、Cartap Hydrochloride、Acetamiprid、Imidacloprid、Glyphosate、Carbendazim、Fosetyl Aluminium、Abamectin、Azoxystrobin、Buprofazin、Fipronil等，来源厂商主要来自中国。

**9(4)本地制造注册（3项）：**
- Pendimethalin Technical 90%（Indus Finechem）
- Propaquizafop Technical 91%（Willowood）
- Bifenthrin Technical 92%（Ralph Agro）
### （二）标签扩展批准
**杀虫剂（10余项）：**
涉及Cyantraniliprole + Lufenuron（茶树）、Fluazaindolazine（石榴线虫）、Betacyfluthrin + Imidacloprid（芒果飞虱）、Spiromesifen（水稻螨类）、Flupyradifurone（辣椒粉虱/蚜虫）、Carbosulfan（黄瓜/辣椒线虫）、Fipronil组合制剂（辣椒蓟马/果实蛀虫）、Cartap + Chlorantraniliprole（甘蔗茎蛀虫）、Flubendiamide + Deltamethrin（玉米秋粘虫）、Spirotetramat（石榴蓟马/黄瓜粉虱）、Acequinocyl（番茄叶螨）等。多数需MRL待定。

**无人机施药（2项）：**
- Betacyfluthrin + Imidacloprid OD用于小麦蚜虫
- Florpyrauxifen-benzyl + Cyhalofop-butyl EC用于直播水稻杂草

**杀菌剂（5项）：**
Penflufen FS（玉米病害）、Hexaconazole + Validamycin（茶树枯萎病）、Carbendazim + Mancozeb（甘蔗病害）、Fluopicolide + Propamocarb（辣椒病害）、Isopyrazam + Difenoconazole（石榴病害），部分需MRL待定。

**除草剂（3项）：**
Imazethapyr SL（高粱杂草）、Clethodim EC（花生杂草）、Topramezone SC（鹰嘴豆杂草）。
### （三）出口批准
- 常规出口、快速出口及星级出口按附件批准
- Deccan Fine Chemicals获准星级出口Metropycybicclone原药
### （四）背书批准
涉及数十家公司的包装变更、来源厂商名称/地址变更、有效期延长等，均获批准并附条件要求提交原版证明文件。

## 四、进口许可新规

**关键变化：** 依据2026年7月8日官方公报，进口许可已成为《杀虫剂规则1971》的法定要求。
**影响：** 所有申请人（包括丙烯腈等非杀虫剂用途）均须取得进口许可。古吉拉特高等法院此前的豁免判决不再适用。相关沟通将同步通知海关及DGFT。指南和表格已作为附件发布。

## 六、行政及管理决定

1. **第472/473次RC会议纪要更正**：涉及硼酸用途、申请人和产品名称的修正
2. **账户冻结处理**：对因未回复KYC缺陷被冻结的账户给予一次性解冻机会（1个月内申请）
3. **指南反馈延期**：整合指南征求意见期延长15天
4. **Chloropicrin注册驳回**：认定其为高危害熏蒸剂，风险远大于效益，不予注册
5. **DME推进剂**：要求Godrej提交技术数据后进一步审议
6. **认证参考物质（CRM）** ：允许通过贸易商供应，但禁止转作农药销售

## 八、关键政策要点

1. **进口许可法定化**：所有杀虫剂及部分非杀虫剂用途物质的进口均须取得许可
2. **异构体数据桥接**：仅可个案评估，不构成一般先例
3. **化学等效性评估**：遵循第449次RC指南（Tier I/Tier II流程）
4. **致突变性数据要求**：9(3)原药申请必须提交完整致突变性数据包
5. **GEO标记要求**：所有海外来源进口注册须提交GEO标记证明
